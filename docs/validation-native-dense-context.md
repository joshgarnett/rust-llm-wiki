# Native dense discovery development control

The cached global dense and hybrid experiment **failed its quality gate**. Each
completed 2/5 positive tasks and lost a fact retained by the lexical baseline.
Public normalized retrieval behavior is unchanged; neither experimental mode is
promoted. The existing 0.2.0 candidate remains available.

## Frozen comparison and result

Six exposed development questions comprised five positive tasks and one absent
measurement. The same normalized source publication, retained embedding snapshot,
release-opt3 native ARM64 executable and budgets served all three arms. Unlike the
[earlier allocation control](validation-location-allocation.md), semantic discovery
could select owners outside the lexical candidate universe. Winning owners were
authenticated and exact units rerendered before producing cited context. The
retained embedding snapshot did not establish complete Current coverage.

All eighteen rotated outcomes returned. Neither candidate met the prospectively
frozen four-of-five threshold or the no-baseline-proposition-loss requirement.
The absent measurement remained unsupported in all arms. No generated answer or
unseen HIGH evaluation ran.

Independent inspection localized remaining losses after owner discovery: the
testing owner contributed only closing praise rather than the testing method;
the corruption owner was omitted at unit allocation while backup passages filled
context; guidance within another selected owner was lost. This supports stopping
this iteration, rather than another discovery rewrite or cap/weight tuning.

## Integrity, mechanics and limits

All **79/79 Current source citations** passed independent source/revision,
UTF-8 range, full-content and quote-hash checks. Every returned context respected
its reported byte/token, proof, scan and time limits. The original source/cache
inventories and protected copied files retained bytes and mtimes; only declared
owned derived SQLite SHM files changed.

The finite native owner completed 21 calls in 6.257 seconds: one six-query cache
preflight, eighteen outcomes and two mechanics groups. Paraphrased-owner discovery
passed. The title-refresh group failed an incorrect fixture expectation: changing
the mutable Source title preserves its immutable Revision title and rendered
input, so cached retrieval should remain valid. This does not establish a stale
byte or citation defect. Six remaining mechanics groups were unrun in that owner.
The original failure is preserved; any subsequent fixture-correctness checkpoint
is separate and cannot turn this quality comparison into a pass.

A separate post-failure correctness checkpoint subsequently passed the corrected
title fixture and all six previously unrun groups. It covers new-owner hybrid
fallback, filtering, withdrawal/history, malformed cache inputs, held readers,
embedding-cache loss and selected external-edit/final-proof refusal. The original
paraphrased-owner group was reused. No quality output was rerun, and public
normalized preparation/full catalog reconstruction remain outside these groups.

Three focused fusion regressions and all 28 semantic integration tests passed at
the planned release checkpoint. Integration providers were local mocks. Earlier
sandbox/startup and compile failures remain recorded; no tests passed in those
attempts. Detailed pins and raw reports remain local execution evidence.

The small fixture contained 52 canonical files / 333,618 bytes. Exact vector scans
are diagnostic and cannot qualify the fast 25k gate, even if these timings fit.
Public normalized embedding preparation, scalable discovery, query-mode parity,
unseen native HIGH and representative capacity remain open.
