# Accepted 25K Source import mechanics

One normalized wiki imported **25,000 distinct Sources totaling 2,500,000,000
input bytes**, with complete immutable-byte and indexed-identity reconciliation.
Independent actual-outcome review accepted this milestone on 2026-10-09.
All 53 fixed public commands and all 57 adapter proofs passed;
no failed command, retry or excluded run was hidden by the result.

The corpus contains 24,998 varied synthetic documents and two licensed Cargo
documentation copies adapted only by adding prefixes. These are development
mechanics inputs; they do not establish representative retrieval quality.

## Executed workflow and preservation

The accepted B3 executable was version 0.2.0 on native macOS ARM64, with verified
actual release optimization level 3 and debug level 0. The supported eight-item
group and 64-group invocation limit were an **unqualified setting**, not a new
default recommendation. The [public importer](source-imports.md) ran offline
against one vault whose path contained spaces, with no provider calls.

The fixed sequence was init, normalized rebuild, prepare, one run, 48 resumes
and final status. It committed all 3,125 eight-item journal groups. Progress
advanced by 64 groups until the final 53; intentional partial responses cleared
at completion, with no pending Change, group or item.

Every prepared input matched its immutable `original.bin` and `content.md`
byte-for-byte. All 25,000 unique Source/Revision pairs, ownership, history,
extraction hashes and input hashes reconciled with the manifest and mapping.
Independent review reconciled every mapping row and committed journal frame,
and inspected the adapter's complete retained payload proofs without repeating
the bulk reads. Quiescent index membership contained exactly 25,000 Current
captured members with matching Source, Revision, path and content hash.
Authority, publication pointer and database custody agreed at Snapshot generation
3,126. Both Cargo documents' actual identities and provenance were reconciled;
that verification does not establish required-fact coverage.
