# lwiki 0.1.1 release verification

The [draft v0.1.1 release](https://github.com/joshgarnett/rust-llm-wiki/releases/tag/untagged-2e63cc6c5ce4b7acd4d4) contains twelve assets: six native archives and six SHA-256 files. Annotated tag `v0.1.1` points to **258689d90d301f3b1ed4f7e12cf8b4f71a296141**, the implementation commit pushed to main. The final documentation-only evidence commit does not change the tagged product source. Existing draft v0.1.0 was left unchanged.

[Release build 36631455854](https://github.com/joshgarnett/rust-llm-wiki/actions/runs/36631455854) passed native Linux GNU, macOS and Windows builds for x64 and ARM64. [CI 36631438819](https://github.com/joshgarnett/rust-llm-wiki/actions/runs/36631438819) passed all three jobs on the same commit. Unix jobs ran format, lint, CLI/tooling smoke checks and the optimized skill recipe; Windows compiled all source/test targets and exercised copied-binary version/capability output. These short platform gates are distinct from the complete local recovery suite.

All downloaded artifacts passed `scripts/verify_release.py`: exact clean source commit, host/target, version 0.1.1, archive member set, executable hash and SHA-256 file. Native ELF, Mach-O and PE architectures were checked independently. All twelve uploaded GitHub asset digests match the local files. Authenticated `gh release download v0.1.1` was tested for Apple Silicon; the returned archive is byte-identical to the tested Actions artifact.

The downloaded Apple Silicon binary passed `codesign --verify --strict --verbose=4`, `--version`, and all thirty commands in `scripts/manual_smoke.py`. The script used a new disposable vault and no network/provider configuration, reproducing graph review after refresh, current search deduplication, agent research import/replay/citations, withdrawal and clean vault checks. Exact hashes, run/job URLs, build metadata and retained smoke paths are in `RELEASE-0.1.1-checks.json`.

Local acceptance before push covered 557 Rust parent cases across 48 unique Bazel targets and affected continuations, 41 Python tooling tests and the 36-step skill recipe. See `AGENT-RESEARCH.md` and `AGENT-RESEARCH-checks.json` for failed initial fixtures and final results; no single initially green full invocation is claimed.

Use [the complete test-agent handoff](../../testing-0.1.1.md) for downloads, disposable offline checks, agent research submissions, live embedding/generation regressions and reporting. [Release notes](../../release-notes-0.1.1.md) list the changes since 0.1.0. This remains a draft per the owner's preference. No live gateway credentials, paid provider calls, real vault edits, host installation or signing changes were used. Windows vault writes remain unsupported; native build success does not qualify crash recovery on every platform. The old installed-copy macOS SIGKILL remains undiagnosed.
