# P17 architecture and integration API

The five retrieval leaves own render-v1 and original byte mappings, deterministic UTF-8 segmentation, explicit embedding-space identity, disposable SQLite normalized f32 vectors and generation memberships, exact bounded top-k scanning, and owner-collapsed named RRF contributions. The application leaf owns explicit check/sync, retained active configuration, replacement coverage, paid query misses, and the production Dispatcher/JobLedger lifecycle. Fresh eligible rendered inputs intersect the cache before scoring; generation memberships are rebuildable publication checkpoints. Run/receipt bookkeeping is excluded from the corpus.

Root integration is now implemented: public leaf modules; semantic/hybrid search modes and semantic graph seeds; `graph::query::from_seeds` and uncapped lexical candidate channels; verified context retrieval callback; preserved graph result and actual `network_used` result fields.

Library APIs use explicit injectable `EmbeddingRuntime { service: &TrustedService, dispatcher: &Dispatcher, job_options, limits, deadline_ms }`, with no ambient config or credential discovery. `OfflineApp::embeddings_check(settings, runtime, probe)` and `embeddings_sync(settings, runtime)` perform explicit work. `semantic_search(text, plan, runtime, no_sync, fallback, graph)`, `semantic_graph(text, plan, runtime, no_sync, fallback)` and `semantic_context(text, request, runtime, no_sync, fallback)` prepare paid query vectors once, outside final proof/retry. Cache hits need no runtime, trust check or helper invocation. Root owns native CLI runtime/config/profile resolution through `RemoteArguments.runtime(app, profile, capability)`.

Space identity hashes representation fields only: endpoint/profile/service identity, model/revision, configured dimensions, prefixes, cosine/normalization and renderer versions. Retained segmentation policy is atomically published with complete replacement membership; active checks compare the complete retained spec. A newly trusted service must independently match the retained space. Partial replacement retains the old active space and never blends spaces.

Paid vectors are staged unavailable, then receive real canonical validated receipts containing exact vector-cache references. Outputs commit, accounting settles, cache references verify, rows become available, and ledger tasks complete. Typed retained decode distinguishes recoverable local failures from proven invalid responses. Complete protected-spool orphans recover without resend; incomplete body-only orphans preserve unknown exposure. Descriptor length/hash/canonical bytes and target proofs are checked before cache writes; source changes withhold membership and preserve settled accounting. Receipt generation changes trigger fresh target rematerialization rather than whole-generation equality across HTTP.

Checks use only disposable fixture vaults, synthetic vectors, injected production transport/ledger faults and native loopback HTTP. Cargo is serialized by the root; worker formats only leased files and records actual checks and qualification limits in P17.md.
