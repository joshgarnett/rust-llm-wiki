# P20 ledger epochs and atomic frontier leaf

Implemented leased `src/jobs/research.rs` and `src/jobs/research_tests.rs`; shared jobs/types/replay/ledger wiring remains root-owned. The leaf provides pure genesis/transition validation, typed role/profile/config/endpoint binding helpers, live guarded source/descriptor/output/receipt checks, trusted-service rebind, atomic source/round admissions, support assessments, durable retry schedules, and stable ordered batch reservation.

Rebind retains immutable genesis, historical task definitions, attempts, holds, lifetime limits/deadline, origins, rounds and no-progress state. It requires paused/stopped quiescence; terminal spool observations are journal-reconciled before the replay barrier. Exact transition retries return their authenticated EventRef; changed payloads conflict. Full task equality includes priority/dependencies. Retired tasks remain historical and active dependency closure is checked.

Fetch admission verifies normalized URL origins against actual canonical descriptors. Redirects require the completed parent, validated receipt, protected metadata/body hashes, exact Location target and bounded hop ancestry; they retain their original source slot. Assessment support groups derive from verified quote hashes, preventing mirrored quotation bytes from adding new groups. Batch admission recomputes the eligible priority/key prefix under one lock, includes persisted retry times, and returns reservations already durably admitted when a later budget/clock gate stops the wave.
