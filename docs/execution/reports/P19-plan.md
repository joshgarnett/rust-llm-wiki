# P19 proposed interfaces and architecture

Baseline: P16 cbaf990. Leases are search_wire.rs, public_fetch.rs, web_normalize.rs, acquire.rs, research_acquisition.rs, fixtures/p19, and P19 reports only. Root owns shared registration and Cargo. No nested delegation or live requests.

Search adds `RemoteOperation::Search { query, count, page }`, `WireContract::Search(SearchContract)` and `ValidatedOutput::Search { leads: Vec<SearchLead> }`; `SearchLead` carries URL/title/snippet/rank and is deliberately not a citation. Leaf sealing uses a trusted service and verifies task fingerprints, GET URL q/count/offset, no body, bounded response and SearchResult upper bound. Root routes prepare/observe/decode and preserves configured endpoint trust while allowing this sealed GET URL. Native transport may validate against the leaf recomputation.

Fetch adds `RemoteOperation::Fetch { url, limits: FetchLimits }`. `FetchLimits` has compressed/expanded bytes, timeout/connect timeout and redirects, persisted in immutable input; no arbitrary headers. The root `Dispatcher::execute_public(ledger,key,&PublicFetchOptions)` delegates to the leased leaf's crate-private dispatch. It uses the same ledger reserve, dispatch intent, opaque begin_send, actual-entry authorization check, raw response spool, materialization and settlement. No SendAuthorization constructor or new accounting journal exists. Public fingerprint helpers fix the profile to public-fetch-v1 and bind limits, URL and GET representation. Run scope includes its settings fingerprint; explicit URL never resolves a search service.

Injectable resolver and connection backend are below the actual production boundary. After one admitted hop, resolve the hostname, reject every private/reserved/mapped/nonpublic answer and pin all public answers. Connector receives a private-construction request with fixed method/headers, validated IPs and TLS hostname, and only runs after the authorization's final live actual-poll proof. Native reqwest disables proxies, automatic redirects/retries and decompression, uses resolve_to_addrs, HTTP1, TLS verification and bounded streamed chunks. Redirects return Location for a separately persisted/admitted task; the acquire frontier caps redirects and rejects HTTPS downgrade/credentials before creating the next task. Mock resolvers/connections exercise this same path.

Raw bytes are durably spooled before manual bounded gzip/zlib decompression and deterministic HTML/text normalization. Root integrated flate2=1.1.10 with rust_backend. Unknown content encodings/media/charsets stay unsupported. Normalizer has bounded UTF8 scanning, script/style/template/comment suppression, deterministic whitespace and common/numeric entities, with no execution/subresources. Output is an immutable P04 capture revision. Exact original/final URL, redirect statuses, media, acquisition UTC, hashes, normalizer version and encoding are embedded as canonical JSON in the new immutable revision body. Existing revision-note hash dependencies cover that provenance. Unsupported/auth/robots/unavailable produce typed gaps and unsupported captures where bytes were received. Response robots denial/directives are explicit gaps; the contract does not mandate an implicit robots.txt workflow.

Public unauthenticated website GETs use the explicitly named unmetered-public-fetch-v1 rate card, with empty billable classes and zero provider API fee in the run currency. Network/ISP costs are outside provider-fee accounting. Search/model operations cannot inherit this assumption. Request/byte/concurrency/deadline admission remains enforced.

Before normalization, selected response headers/URL/time/hash/limits survive restart in the optional strict typed acquisition metadata field integrated by root in the existing protected, hashed response metadata spool. The strict leaf metadata DTO excludes raw bytes, cookies and arbitrary/auth headers; recovery binds its URL/limits/hash to the retained canonical descriptor, attempt wire hash and exact raw spool and returns data/materialization only. No resend authority is reconstructed. Existing ledger replay repairs a raw+metadata orphan interrupted before Received; the targeted acquisition bridge test proves it.

Acquire exposes conservative URL identity (remove fragment/default-port normalization only; query content/order retained), overlapping lead dedup retaining origins, content-hash grouping retaining distinct origins, hop planning and capture planning. Full research run orchestrator is P20.

Root deltas integrated: module registrations; RemoteOperation and output/contract variants above; Dispatcher execute_public delegate; native trusted search URL validation; flate2 dependency/lock; typed acquisition metadata in protected spool; exhaustive no-model Search observation. Targeted root-snapshot Cargo grant completed: all18 tests pass. Detailed evidence, limits and leases are in P19.md.
