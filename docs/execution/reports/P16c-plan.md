## Shared boundary and minimal deltas

Keep RemoteInput and PreparedWire opaque authority separation. Public RemoteInput carries data only; no public constructor can supply arbitrary encoded bytes or TokenBound as dispatcher proof. Root replaces production stubs with sealed module calls, preserving actual retained input/path/hash/length/source checks and task capability/Probe-role validation.

Proposed provider-private pure entrypoints for each leaf:

```rust
prepare(service: &TrustedService, task: &TaskSpec,
        input: &RemoteInput, purpose: DispatchPurpose) -> Result<PreparedWire>
observe(prepared: &PreparedWire, reply: &TransportReply) -> ObservedUsage
decode(prepared: &PreparedWire, reply: &TransportReply) -> Result<ValidatedOutput>
```

Root adds PreparedWire.contract: WireContract, provider-private and non-Deserialize. It seals normalized role/model/revision/settings, input count/hashes, requested versus established dimensions, generation response schema/compiled validator and a private BoundBasis. A common pure dispatcher preparation helper computes canonical logical input, prompt/schema/model/settings fingerprints, exact method/full URL/nonsecret ordinary headers/body wire hash and AttemptBound fingerprint; encoders cannot independently weaken shared bindings. Body serialization uses a capped writer, refusing overflow before growing beyond the trusted/run ceiling. Secrets and secret-derived hashes never enter public fingerprints. No additional dependency is requested: use cached serde_json and jsonschema0.58.2; HTTP remains .b's pinned reqwest implementation.

Observe and decode must borrow the prepared contract, rather than current purpose-only decoding/bound-only observation. This is required to validate vector membership/dimensions, returned model policy and class accounting. Observe billing independently before knowledge decoding; invalid knowledge does not discard valid paid usage. Probe validates the same role-specific reply before reducing it to Probe output and never activates an embedding space or imports generation.

Root-approved violation integration adds only private ObservedUsage.contract_violation: Option<WireContractViolation>, initially ReturnedModelMismatch or UnexpectedBillableClass. A valid observed positive reasoning/audio/prediction class forbidden by the sealed model contract, or valid contradictory returned model, drives the fixed metadata.failure_code=wire_contract_violation before owned spool/metadata retention. Missing counts, malformed usage, vector/schema/refusal failures and ordinary transport errors never generate that marker. Root extends the existing ledger observation_violation predicate to recognize this exact safe code; record_response, refresh_observations and replay durably retain existing BoundViolated/Reconciled behavior from hash-bound Received metadata before any output/retry. This preserves the flag across a crash between Received and marking the violation. No new ledger method/event/schema is proposed. The marker only invalidates a guarantee and preserves accounting; it never refunds, grants authority or converts unknown counts to0. The dispatcher must combine normal HTTP/output failure labeling with this marker without overwriting it.

## Embedding encoder and decoder

Encode exact configured model, ordered UTF8 inputs, encoding_format=float and dimensions only for an explicit configured Fixed value. Auto omits that request parameter; existing expected space dimensions remain a decoder check. Check each text hash against actual UTF8 bytes, reject empty text/batches, preserve duplicate input positions, and enforce item/request caps before serialization. Profile Fixed and caller-established expected dimensions must agree. Default limits32items/256KiB request/8MiB response; existing trusted overrides stay within root bounds.

Decode one full bounded JSON document, rejecting duplicate keys everywhere, trailing content, excessive depth and invalid scalars. Require list/data entries with integer indices, one vector per requested position, no missing/duplicate/out-of-range index and no partial result; reorder by index. Coordinates must be JSON numbers finite as f64 and after f32 conversion, with nonzero finite f64 sum of squared f32 coordinates. Reject empty or mixed-size vectors, and enforce fixed/established dimensions. Default auto dimension comes from this valid batch only and is not activated by a probe. Allocate vector capacity from bounded actual count and trusted dimension limits, not remote declarations; propose hard1048576 total coordinates plus existing65536 per-vector limit. Preserve all item hashes/positions and representation fingerprint for P17 materialization; do not collapse repeated text into fewer outputs or bill the repeated inputs once.

Top-level model is required, bounded and control-free. Proven official contracts require the corresponding documented model ID; a conflicting response is unsuccessful with paid metadata retained and invalidates its claimed model-dependent bound. Generic profiles record returned model, with P17 guarding previously established returned identity across batches. Duplicate JSON model fields refuse, and item-level unsupported model/unknown fields never override the top-level contract. Official Fixed dimensions also cannot exceed the documented model's default maximum. Retrieval owns normalization/cache activation; no embeddings are silently regenerated after cache loss.

## Generation encoder and decoder

Encode model, exactly one selected system/developer instruction message plus one user data message, stream=false, n=1 and exactly the configured output-limit field. Require positive request max_output_tokens no greater than explicit service cap; defaults are selected and fingerprinted, never retried speculatively. No tools/functions, multimodal content, prediction, temperature or provider-specific fallback fields. Source data and output schema cannot override roles, URL, auth, limits or options.

text-json sends no response_format. The full returned assistant string must parse as one strict JSON value and satisfy the original output schema locally; no prose/fence stripping or regex recovery. json-schema adds a stable name, strict=true and the exact locally validated schema. Reject unsupported provider schemas before send; never weaken or silently remove constraints. Local schema preparation is capped64KiB/4096nodes/depth32, draft2020-12, no external references or recursive reference cycles. Use cached jsonschema::options().offline() and reject nonlocal refs proactively. Local validation retains published extraction oneOf/allOf, bounded pattern, date and scalar/object/array constraints, even when those require text-json rather than the provider's narrower strict subset. Set the cached PatternOptions::regex linear-time engine with bounded compilation/DFA sizes; reject lookarounds/backreferences and arbitrary custom formats/extensions. Compile/validate built-in date formats locally with no IO. Bound local reference expansion/composition work, not only raw schema nodes; refuse unbounded reference fanout. Extraction quote/source-chain semantics remain graph::wire/import responsibility after this adapter validates JSON/schema.

Successful chat decode requires one choice, index0, message.role=assistant, bounded text content and finish_reason=stop. Null/missing/nontext content, refusal, tool_calls/function_call, length/content_filter/other finish reason, multiple choices, malformed JSON or schema failure produce safe unsuccessful output and retained receipt. Permit absent/null refusal and absent/null/empty tool arrays only as documented inert forms; every nonempty tool result refuses and is never executed. Disallow other actionable extensions; validate optional inert provider envelope metadata rather than accepting arbitrary unknown shapes. No output repair or fallback generation is automatic.

## Usage observer

Start with actual serialized request_bytes and measured transport response_bytes; byte lengths count UTF8 bytes, not characters or estimates. The transport-observed count remains authoritative on overflow. Parse only the whole bounded response; malformed/duplicate/deep JSON supplies no guessed fragment usage. Request IDs/models are bounded allowlisted observations passed through .b secret redaction. Missing/null usage or subset fields remain Unknown; malformed values make the relevant observation unknown and output unsuccessful, without erasing independently valid observed totals.

For chat, prompt_tokens is total input; cached_tokens is a subset. When both are valid integer counts with cached<=prompt, Input=prompt−cached and CachedInput=cached. completion_tokens includes every generated token; when valid reasoning_tokens<=completion, Output=completion−reasoning and Reasoning=reasoning. Absent detail counts leave those partitioned classes Unknown rather than assuming zero or charging total+subset twice. Validate total_tokens=prompt+completion when present with checked arithmetic, and reject unsupported nonzero audio/prediction billing shapes for this text-only encoder. For embeddings, prompt_tokens is Input; supplied total_tokens must agree, and no missing usage means free work.

Compute cost only from known complete applicable class counts and the retained valid RateCard, using existing checked upward-rounded rate helpers and request fee exactly once. Unknown counts/prices/currency mismatch never produce Known0. Billing observation survives refusal/truncation/vector/schema failure when the usage envelope is valid. Overspend is recorded by existing ledger breach rules, not clamped to the reservation. Retry401/429/selected5xx remains .b's accounted policy, never a wire-module callback.
