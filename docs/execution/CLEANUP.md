## Objective

Make lwiki useful for **agents and humans working on the same maintained wiki**. A successful research task leaves understandable, linked, cited knowledge that can be edited and refreshed. Agents should retrieve focused context and receive clear next actions. Humans should comfortably browse and edit normal Markdown. Metadata, evidence, recovery and accounting support that experience; operational files should not overwhelm it.

The owner's example had 451 visible files for six captured source revisions, one maintained page, ten extraction packets and one extraction record. Approximately 414 files were under `changes/` and `runs/`, including some useful reports. This is a historical count derived from the supplied tree, not disk usage. The accepted cleanup below measures physical bytes and duplicates, bounds retention and protects recovery/accounting authority.
