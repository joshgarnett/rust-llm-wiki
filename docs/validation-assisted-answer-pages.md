# Assisted answers and maintained cited Pages

The complete supported-answer → typed draft Page → guarded Source reconciliation
workflow passes its independent scoped development gate. Three exposed questions
produce complete supported answers and Pages; a real Source refresh updates all
three, and withdrawal leaves explicit current-support limitations while retaining
history, complementary live support and the author's note.

This demonstrates the existing runtime's assisted workflow. There is **no measured
incremental native or product quality gain**, and no fair comparison with a
competent user of the previous guide. Native completeness remains the failed
9/28 facts and 2/10 positive tasks. Semantic/HIGH, the remaining complete 10K
lifecycle, 25K and full-release gates remain open.

## Implemented route

The maintained [answer and Page recipe](../skills/llm-wiki/references/cited-page.md)
now connects ordinary context, supported answering, optional one-shot selection,
typed publication and author-preserving reconciliation. Use the actual returned
text as evidence. When it already supports the question, answer directly.

When a supported lexical context route lacks a condition, the existing
`--prepare-selection` interface can expose complementary candidate passages.
A fresh host selector receives the **original public task and the exact unaltered
native selector input**. A keyword retrieval query does not replace the user's
conditions. Its ID-only reply is replayed against the identical query, filters,
limits and publication before writes change that snapshot. Candidate cards alone
are not final answer support. Count preparation, replay and host input against
the declared allowances; preparation can exceed the final context byte limit.

Save an answer only when authorized. Exact returned SourceRefs supply
`page init/put --source-refs`; the CLI authenticates them and derives links from
the allocated Page path. Following Source changes, reacquire support and reconcile
the whole Page under its fresh author hash. Preserve author content and metadata.
Immutable evidence can remain readable after losing current eligibility; citation
integrity and lifecycle labels do not establish entailment or procedural approval.

## Reproduction and packaging limits

Use a disposable normalized vault with two approved procedures, separated role
facts and plausible unrelated observations. Freeze representative conditions and
finite native/host limits before outputs. Follow the maintained recipe, finish
selection before Page writes, then create and discover drafts. Apply an independent
author note and stale-guard control. Refresh one shared Source with genuinely
changed bytes, reconcile every dependent Page, withdraw that same Source and
verify both retained history and the surviving complementary fact. Keep the
selected-record absence question scoped to its original Source. An independent
critic must inspect actual returned evidence and saved prose.

The existing embedded export and typed-Page runtime supplied the commands.

candidate016 still embeds the previous guide. Its runtime checks are reused.
