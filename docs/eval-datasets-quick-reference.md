# Evaluation datasets and approach: quick reference

Updated 2026-10-05. This catalogs the datasets and fixture families recorded in this repository's evaluation research, acquisitions and curated validation summaries. **Acquired data, passing mechanics and high development scores are different from accepted end-user quality. Native HIGH and representative 25k capacity remain unqualified.** No new experiment or provider call was made for this reference.

Use [the context protocol](evaluating-context.md), [dataset acquisition/adaptation details](eval-datasets.md), [critic workflow](testing-usability.md), [quality gates](rag-quality-targets.md) and [capacity protocol](testing-large-vaults.md) for implementation or a new run. Local `.artifacts/` manifests mentioned below are optional historical evidence; tracked guides/scripts supply the available fresh-checkout reproduction routes. Unknown facts are marked unavailable rather than inferred from a paper, mirror or vendor score.

## At a glance

“Considered” means researched; “metadata” means notices/evaluator/schema material retained without the data archive; “acquired” means source/task bytes retained; “prepared” means a local source/label adaptation exists; “evaluated” means actual CLI outputs were measured. All inspected/evaluated public examples are development data, even when the upstream split is called `test`.

## Public datasets acquired or prepared

### QASPER v0.3

- **Origin / terms:** Dasigi et al., [NAACL 2021 paper](https://aclanthology.org/2021.naacl-main.365/), [official AllenAI dataset card](https://huggingface.co/datasets/allenai/qasper). CC BY 4.0; full paper text originates in S2ORC and retains author rights/notices. Acquired 2026-10-03. Original releases contain 888 train, 281 dev and 416 test paper IDs; the adapter checks disjointness.
- **Supervision:** Human natural questions, extractive/free-form/yes-no reference answers, paragraph evidence, selected sentence highlights and unanswerability. Multiple references remain alternatives. No independent semantic propositions are fabricated by the adapter.
- **Local samples:** `qasper-mini-v1` uses train/dev/test paper counts 4/4/8, eligible questions 13/10/26, positive counts 11/10/25, absent counts 2/0/1 and source bytes 100,475/99,421/209,253. Explicit exclusions are 5/5/9. `qasper-text-v1` uses 12/24/24 papers, 31/67/61 eligible questions, 29/63/58 positives, 2/4/3 absent, bytes 283,722/614,651/747,203 and exclusions 9/25/29.
- **Construction:** Fixed paper-ID hash ordering with seed `lwiki-qasper-text-v1`, independent of retrieval outcomes. Full Markdown retains original paragraphs, adds title/section boundaries and marks captions without images. Figure/table-image dependencies, missing/disagreeing annotations and unmappable evidence stay in exclusion audits. Gold UTF-8 offsets, questions and answers stay outside the source directory. Global queries use the declared `paper-title-prefix-v1`; `--paper-local --query-style original` scopes to the designated paper and makes source hits trivial. Negative labels apply to that paper only.
- **Use / limits:** First supported public location baseline; mini train+dev is eight papers/23 tasks with 21 positives. A development stage-loss diagnostic found complete paragraphs in all/top80 units for 21/21 positives, top2-per-paper for 5/21 and prototype3 citations for 3/21; exact legal gold packets fit all 21, maximum 4,620 bytes/four passages. This diagnoses loss, not semantic task success. Public test was prepared/validated but not retrieval-evaluated; larger-sample evaluation is not recorded. The dev mini split has no absent cases. Prepared public test is not a private/pretraining-secret holdout.
- **Reproduce / pins:** [Tracked preparation script](../scripts/prepare_qasper.py), [download URLs, hashes and commands](evaluating-context.md#acquire-and-prepare-from-a-fresh-checkout), [offline runner](../scripts/context_eval.py). Train/dev archive: 10,835,856 bytes, SHA256 `a28fdf966db827bcee3d873107d6b6669864fb7ca8fbf73a192f5e39191bdb5a`; test/evaluator archive: 3,865,061 bytes, `72a52a41193e2838b8074f80ac074b94f956b84886c36a61c58a7df4171bdd72`. Moving card bytes are separately hashed. Original mini manifest `1ffeeb0b05ab3a098b97d6c04efffc08f0d8739d1730faa1a0613d0422a59a14`; adding supported notices creates a new manifest, so old mappings cannot be reused. Optional local manifests: `.artifacts/eval-research/{qasper-mini-v1,qasper-text-v1}/manifest.json`.

### ConditionalQA v1_0

- **Origin / terms:** Sun et al., [ACL 2022 paper](https://aclanthology.org/2022.acl-long.253/), [project](https://haitian-sun.github.io/conditionalqa/), repository pin `77bd295952daf415548b3244db10880d3d55cfe0`; acquired 2026-10-03. Dataset declaration is CC BY-SA 4.0. Repository `LISCENSE` is BSD-2-Clause software text, not a replacement data grant. Preserve both notices, historical GOV.UK attribution/URLs and research-use disclaimer.
- **Counts:** 652 documents; 2,338 train questions: 550 conditioned, 1,697 answerable without conditions, 91 unanswerable. The supported sample takes eight per stratum: 24 tasks over 24 documents, 148,336 rendered UTF-8 bytes. `--corpus all` renders all 652 documents / 5,073,865 bytes using the same selected tasks; it is a distinct development protocol. Train JSON is 2,386,451 bytes, documents JSON 6,286,258 bytes.
- **Construction:** Deterministic stratum/ID hash selection. Query preserves **scenario plus question**; conditions can disappear from a short question alone. V2 converts HTML-like fragments to mapped Markdown, retaining raw JSON/entry maps and exact transformed evidence offsets. The complete answer/condition set is one required set, not alternatives that reward just one answer. Labels never enter the source corpus. Ambiguous exact occurrences remain alternatives; mapping failures stop preparation without silently reducing the denominator. The default selected corpus omits global distractors. Negatives remain designated-document scoped even with the full corpus.
- **Observed development:** Raw-HTML v1 supplied zero Markdown blocks/citations and retained one full-query limit error. V2 with the former 64-term ceiling yielded one error/24, 92 valid citations, 6/16 exhaustive-gold-complete and 64.0% mean evidence-byte coverage. Paired full-query admission at 16 KiB/256 terms yielded zero errors, 96 citations, 16/16 designated source hits, unchanged 6/16 strict completion and 68.7% mean coverage. These are location diagnostics, not condition-aware semantics or success on the eight absent cases. The official answer evaluator can omit missing predictions from averages; use complete denominators and failed-case zeros.
- **Reproduce / pins:** [Supported guide and all four immutable input hashes](evaluating-conditionalqa.md), [adapter](../scripts/prepare_conditionalqa.py), [acquisition table](eval-datasets.md#reproduce-essential-acquisition). Optional metadata/manifests: `.artifacts/eval-datasets-additional/`, `.artifacts/conditionalqa-adapter/dev-v2/`. Train hash `2976f448bad58efd747c5b7b4127fb3ad7a4834f760e9022c06a86536618bc2d`; document hash `1c977c1b14738b9ce1e53336c5abf3b3de34b72ee24985e7de6d8fae30856c59`.

### WixQA ExpertWritten

- **Origin / terms:** [Publisher dataset](https://huggingface.co/datasets/Wix/WixQA), [original paper](https://arxiv.org/abs/2505.08643). Knowledge-base snapshot 2024-12-02; pinned revision `d662dc42479c14e202eccd832f8c4b66a035c4cc`, acquired 2026-10-03. Card/paper declare MIT; pinned tree has no standalone LICENSE, so preserve the actual declarations rather than inventing license text.
- **Counts / labels:** Acquired 6,221 articles and 200 expert questions: 148 single-article, 46 two-article, six three-plus. All referenced article IDs resolve. Research sample: 22 questions (8/8/6) over 42 articles. Corpus JSONL is 53,743,863 bytes; question JSONL 255,510 bytes. Expert answers and article IDs establish targets/relevance, not exact sufficient spans. Simulated and synthetic question tracks were considered but not acquired here; the paper's 6,222 synthetic pairs differ from this release's 6,221 card/corpus count.
- **Fit / preparation:** Strong realistic support/instruction and multiple-source complement to QASPER. Independently label all required steps, prerequisites/restrictions and supporting passages; allow valid evidence outside the original article-ID list. Scraped heading/list spacing can be damaged, so any formatting repair needs a declared mapped adapter. Raw source sample exists, supported completeness adapter and CLI evaluation are pending. Do not fabricate whole-article gold spans.
- **Exposure:** Sample plus inspected schema row connect 47 questions through 46 article IDs. Exclude that complete connected closure from a future holdout, not only the 22 sampled rows. The original split name `test` does not make inspected questions unseen.
- **Reproduce / pins:** [Pinned corpus/questions/card URLs and SHA256](eval-datasets.md#reproduce-essential-acquisition). Corpus hash `46b852c60b85fb1828e7c6118bb56ba796eba99120a6b69c6b984c06e1c5e1fe`; expert-question hash `a1bb6888a8394f980bc88f0d09b873fcd283ff4c9782600bc203f8103c2f1bad`. Optional research metadata: `.artifacts/eval-datasets-additional/development-samples/wixqa/manifest.json`; the local exposure ledger must be consulted by the independent custodian before new family selection.

### ContractNLI

- **Origin / terms:** Koreeda and Manning, [EMNLP 2021 paper](https://aclanthology.org/2021.findings-emnlp.164/), [official project](https://stanfordnlp.github.io/contract-nli/), archive pin `eced6528dd3c1d14d73f9a87df8f7bdbc03126f9`; acquired 2026-10-03. CC BY 4.0; retain original LICENSE, TERMS, README and contract URLs.
- **Counts / supervision:** 607 NDAs, 17 fixed hypotheses per document, three labels and sentence/list-item character spans. Upstream train has 423 contracts. Local development keeps 12 train contracts / 204 tasks: 96 Entailment, 26 Contradiction, 82 NotMentioned; 826 sampled character spans/indices audited in bounds. Archive is 65,362,913 bytes. First 50 MB acquisition failed; a separately documented 70 MB cap succeeded after size verification.
- **Construction:** Hash-select contracts, retain all hypotheses; do not split rows from one contract/template across development/acceptance. Source is the exact JSON `text` in UTF-8, with no added heading/newline. Character endpoints become verified UTF-8 offsets. Task/designated contract, classification and evidence stay external. All annotations are retained, including redundant support; exhaustive coverage is stricter/different from sufficient evidence. NotMentioned is neither Contradiction nor proven by an empty result.
- **Observed development:** All 204 designated-contract lexical tasks ran offline with zero errors, 793 exact citations, 57/122 exhaustive-evidence-complete (46.7%), mean byte coverage 62.3%, median local subprocess 0.113 seconds. No semantic/classification/negative success grade and no embedding/model calls. Scoped source hits are trivial; 204 repeated hypotheses do not represent 204 diverse natural tasks or compensate for failed multi-source categories.
- **Reproduce / pins:** [Supported guide](evaluating-contractnli.md), [adapter](../scripts/prepare_contractnli.py). Archive SHA256 `e03fc77bbf8b53e2976a250e81d8a294bc3d5e5fb014521e477dee9340d6287b`. Adapter reads bounded train JSON/notices only, not dev/test labels or arbitrary archive extraction. Optional dataset metadata: `.artifacts/contractnli-adapter/dev-v1/manifest.json`.

### MuSiQue-Full v1.0

- **Origin / terms:** Trivedi et al., [TACL 2022 paper](https://aclanthology.org/2022.tacl-1.31/), [author repository](https://github.com/StonyBrookNLP/musique), metadata/evaluator pin `922ac98f19a201998dbdae6d7f2887a5258dbdeb`; metadata acquired 2026-10-03. Explicit data CC BY 4.0. Preserve constituent-ID exclusion lists; seed QA/pretraining exposure can leak dev/test constituents.
- **Task / proposed sample:** Two-to-four-hop questions with supporting paragraphs, answers/aliases, decomposition and paired answerable/missing-bridge versions. Proposed development experiment: 12 pairs per hop count, 36 pairs / 72 instances. This is a proposal, not a prepared denominator. Full release/archive bytes, hash and locally verified schema/counts are unavailable.
- **Status / reproduction:** README, LICENSE, download script and official evaluator retained, data archive **not acquired**. The script points to Google Drive file `1tGdADlNjWFaHLeZZGShh2IRcpO6Lv24h`, `musique_v1.0.zip`; use capped direct acquisition and hash/member inspection, not its install-and-extract script. No supported local adapter or CLI result exists yet.
- **Critical invariant:** Give each instance its own disposable vault with only supplied support/distractors; global pooling can restore a removed bridge and invalidate the negative. Keep both rows of a pair together, unique instance suffixes and shared family ID. Decomposition, bridge answers and support labels stay external. A global version requires a new complete-corpus answerability audit. Official Full grouped sufficiency expects two rows per question ID; paragraph recall/answer overlap do not establish full chain support.

### Cargo release documentation

- **Origin / terms:** [Rust Cargo repository](https://github.com/rust-lang/cargo), primarily MIT OR Apache-2.0; both license files and README retained. Acquired 2026-10-03 at tags 0.84.0 → `5ffbef3211a8c378857905775a15c5b32a174d3b` and 0.85.0 → `66221abdeca2002d318fde6efff516aab091df0e`.
- **Retained inputs:** Per release: `src/doc/src/reference/{config,features,resolver}.md`, `src/doc/src/commands/{cargo-build,cargo-test}.md`. Older/newer source totals 153,561/157,432 bytes; **310,993 bytes across ten files**. Configuration files are 49,530/50,659 bytes. Exact URLs and two configuration hashes are [tracked in the acquisition guide](eval-datasets.md#reproduce-essential-acquisition); remaining per-file hashes live in optional `.artifacts/eval-datasets-additional/acquisition-supplement.json`.
- **Role / status:** Source material for independent QA, not an existing labeled benchmark. Proposed 24 realistic tasks plus refresh/withdrawal controls remain un-authored in this acquisition arm. Two pinned 0.85 documents later served as operational overlays in representative 1k fixtures; those runs do not establish completeness for the proposed 24-task suite.
- **Fit / caveats:** Flags, configuration precedence, code examples, multiple-file facts, versions, restrictions and ordered instructions. Newer config documents `resolver.incompatible-rust-versions`; absence from older documentation says nothing by itself about old executable behavior. Acquire required linked documents before freeze or explicitly label their absence. Group releases in the same family. Replacing one source tests immutable-revision freshness; keeping two source IDs tests historical/conflicting scope. Independently author genuine conflict/precedence controls where release changes do not supply them.

### T²-RAGBench: FinQA development

- **Origin / terms:** [EACL 2026 paper](https://aclanthology.org/2026.eacl-long.8/), [release](https://huggingface.co/datasets/G4KMU/t2-ragbench), revision `adf7fe1541ac37351ce1142544d8e3b43010ed92`; acquired 2026-10-03, CC BY 4.0 card plus upstream source notices. This is the **T² reformulated FinQA dev arm**, not a local evaluation of untouched original FinQA.
- **Counts / construction:** Acquired JSONL 8,604,079 bytes / 883 questions / 299 distinct `context_id`s; contexts total 1,339,673 UTF-8 bytes, largest 9,785, no conflicting shared IDs. Released strings already contain text plus Markdown tables. Preserve exact context bytes and title separately; do not index questions/answers or expand a page context into an entire financial report. Source-only corpus exists/imported; independent operand/header/unit/entity/year/qualifier labels and reformulation auditing are pending. Correct arithmetic is separate from sufficient evidence.
- **Observed development:** A frozen 64-query lexical replay initially failed every question at the 65,536-entry proof ceiling; initial import timed out after 250 sources, with a separately retained continuation for 49. After the marker-probe repair, strict replay: zero errors, 62/64 released-page hits, 512 valid source/citation hashes, median 1.80 seconds. Bounded indexed-source replay: same 62 hits, zero errors, 512 citation audits, median 1.247 seconds; supplemental source sets changed in seven cases. Profiles used 12,000 bytes/3,000 estimated tokens and five-second proof, so neither is native 6 KB HIGH, a controlled speedup nor semantic/numeric completeness.
- **Caveats / pins:** Model-reformulated questions, only some human checked; current card removes VQAonBD for poor reformulations and aggregate counts conflict, so use retained-byte counts. Train file request failed before transfer because advertised length exceeded 50 MB; failure is retained. Dev SHA256 `24048e3250d4178c7fb433aea21439dca23f62abbcbd00d415d9798902a544a5`. [Pinned URL](eval-datasets.md#additional-acquired-development-inputs); optional `.artifacts/eval-2026/t2-finqa-dev-corpus/manifest.json`, acquisition/schema audits and named replay summaries. No maintained dataset-specific sufficient-evidence adapter is recorded.

## How evaluations are run

1. **Declare the user task and independent gate first.** Establish a fresh independent Astra critic before consequential quality changes. Use the public CLI from a disposable vault/outside path with spaces. Cover capture/import, discover, exact cited context/deeper read, authored pages, refresh, withdrawal/history, interruption/resume and cache-loss recovery; also missing inputs, absent facts, conflicting edits, dry-run/offline and finite bounds. Freeze expected propositions, acceptable support, blockers, category floors and score before candidate results. Implementation self-review is not independent acceptance.
2. **Select suitable evidence and isolate labels.** Mix public corpora with independently authored realistic/synthetic tasks: paraphrases, rare identifiers, distant/multiple-source facts, distractors, conflicting versions, conditions, absent bridges and operational errors. Preserve publisher attribution/terms, original bytes, extraction/source maps, UTC acquisition time and immutable hashes. Only source Markdown enters the index; questions, scenarios, decompositions, answers, labels, critic notes and reports stay external.
3. **Split by connected source/task families.** Group duplicates/near-duplicates, contracts/templates, shared article/support graphs, paired missing-bridge instances and historical/current releases. Keep inspected questions development even if upstream calls them test. A custodian retains the new holdout until freeze; exposure consumes it as development, requiring a fresh holdout for another claim. Structural counts are permitted metadata; private expected facts/questions remain unopened here.
4. **Freeze a comparable experiment.** Pin executable/helper/protocol hashes, actual compiler optimization profile, source/revision/mapping hashes, mode/scope/query transformation, segmentation, index generation, all corpus/query caches and every budget/deadline. Acquire all separately authorized query embeddings **before** paired offline replay: provider receipts/history can change the index/FTS statistics. Compare baseline/candidate on identical inputs/caches/budgets. Keep failures, missing vectors, omissions, regressions, exclusions and unknown usage; no cherry-picking or retry-until-pass.
5. **Score distinct outcomes.** Report discovery/source rank and relevance; emitted location/support-set coverage; per-required-fact and strict all-facts completeness; exact Source/Revision/UTF-8/hash citations; freshness/budget/offline/accounting correctness; and workflow task completion. Relevance does not imply enough facts; redundant gold spans are not semantic necessity; exact bytes do not imply entailment or truthful publishers. For future generated answers, judge answer completeness, unsupported claims and abstention coverage separately. Current context-only output has no answer-level abstention classifier.
6. **Attribute failure to its first pipeline loss.** Inspect discovery → source representation/unit construction → candidate packet → selection → final packing/proof. Use prospectively labeled complete/partial/missing/conflicting evidence ablations, matched topic/length/metadata and shuffled locations. After two interventions without whole-task gains or recurring regressions, get fresh architectural review/research instead of parameter tuning. Adapters and component tests cannot alone establish an integrated useful workflow.
7. **Measure costs honestly and replay fixes independently.** Owner-process monotonic clocks measure native intervals; external agent UTC start/end observations have wall-clock limits and are not inference time. Report cold remote acquisition, cached local query, host selection, final replay and end-to-end separately; include failed calls, repeats, model input/calls/tokens/known money and unavailable quantities. Release-performance qualification uses release/opt-level 3, pins profile with binary, and records hardware/RSS/disk. An unoptimized run is diagnostic. Native fault cuts, another-platform cross-build and mock/live providers have separate proof boundaries.

The maintained [context evaluator](../scripts/context_eval.py) imports byte-verified source-only datasets and runs offline location/integrity replay. It does **not** generate answers, call providers/selectors or grade semantics. Defaults: five results, 80 candidates, 1,024-byte excerpts, 6,000 rendered bytes, 1,500 estimated tokens and 65,536 proof entries; pin deadlines separately. Its declared byte/4 estimate is not an exact tokenizer. Multi-document `required_evidence_all_of` is already supported; anchor hits are not all-required-source recall. Inspect command stdout/stderr, warnings and final actual citations, not only scores.

Use small deterministic mocks/fixtures in fast CI, pinned public development offline runs for broader regression, and separately authorized finite live experiments for provider/model questions. Never claim a mock demonstrates live compatibility or a cross-build proves native crash recovery. Keep credentials protected and retain unresolved accounting holds.

### Native versus host-assisted workflows

Native deterministic context and explicit `--prepare-selection` → one fresh host selector → `--selection FILE` are separate arms. A selector sees only its exact task and candidate evidence, never expected facts or other questions. It supplies a bounded fingerprint-bound list of supplied IDs; final native code checks snapshot/revision/span authority and packs original bytes. No retries, extra retrieval, repair or answer synthesis unless a different protocol was declared in advance.

The general context-selection protocol reserves a 1,024-byte declared transport wrapper inside a 131,072-byte application input ceiling (product task at most 130,048), up to 20 distinct selected IDs and 4,096-byte reply. Per-run compact trial limits can be tighter and must be reported independently. Slice transport must account for the complete aggregate input; splitting does not reduce total model context. Harness/system input, actual model tokens/reasoning/cost are unavailable unless the platform reports them. Replay latency measures final local validation/packing only: join preparation, selector and orchestration records before reporting end-to-end.
