# User manual

Start with [one offline wiki and a captured fact](getting-started.md). Then choose
an everyday task or open a reference when you need it.

| Task | Guide |
| --- | --- |
| Obtain, verify, upgrade or remove a binary | [Installation](install.md) |
| Choose a wiki, use an existing editor folder, capture/refresh notes, edit or move a Page | [Everyday use](everyday-use.md) |
| Interpret health, restore exact author bytes, or back up a complete wiki | [Recovery](recovery.md) |
| Search, follow citations, inspect named neighbors, or select evidence with a host | [Retrieval reference](retrieval.md) |
| Import collections, refresh batches, configure remote work, or inspect experimental relations | [Sources and providers](sources-and-providers.md) |
| Export an agent workflow or understand the file format | [Integration and format](integration.md) |

The running binary's `--help`, `capabilities` and `schema NAME` describe its exact
commands and schemas. Current machine envelopes use output v2; the v1 schema
remains available for older output. Inspect errors, warnings, selection, freshness
and partial outcomes before relying on command data. Release and installed-host
qualification remain pending; [validation status](../developer/validation-status.md)
records those separate gates.
