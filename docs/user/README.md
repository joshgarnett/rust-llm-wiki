# User manual

[Get started](getting-started.md) to create a wiki, connect your agent and use
your own notes. Then choose a guide for the task you want to do.

| Task | Guide |
| --- | --- |
| Install or remove lwiki | [Installation](install.md) |
| Choose a wiki, capture notes, and create or edit a page | [Everyday use](everyday-use.md) |
| Find a fact and read its cited passage | [Search and citations](retrieval.md) |
| Import a collection or set up search by meaning | [Sources and providers](sources-and-providers.md) |
| Connect another agent or understand the wiki files | [Agent integration and files](integration.md) |
| Diagnose a problem, back up or restore a wiki | [Troubleshooting and backups](recovery.md) |

For a command's options, run `lwiki COMMAND --help`, such as `lwiki source add
--help`. Agents and scripts can use `--json` for structured output, `capabilities`
to discover supported commands, and `schema NAME` to inspect a request format.
