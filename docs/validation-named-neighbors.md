# Validation: normalized named Entity neighbors

The implemented workflow finds an Entity through selected search, inspects its
accepted Current neighbors, reads exact supporting and contrary source spans,
then retains correct eligibility through refresh, withdrawal, backup and offline
cache reconstruction. Independent Astra acceptance passes at **9.5/10**, with
**all thirteen mandatory tasks complete and zero correctness blockers**.

The [user guide](named-neighbors.md) describes the interface. This slice uses an
existing reviewed graph. Normalized graph extraction/import/resolution/review,
general graph query, historical adjacency, literal search parity, automatic
evidence completeness, native HIGH and representative 25k/~2.5GB capacity remain
separate open work. The [contract map](current-contracts.md) records that boundary.

## Public workflow acceptance

The thirteen mandatory tasks cover discovery and exact reads; Current identity
with Unsupported description; opposition and eligibility; depth/caps/filtering;
absent and ambiguous IDs; hub partial output; refresh with surviving alternate
support; last-support withdrawal/history; selected edits and reconciliation;
the reached final recheck cut; backup/cache loss/rebuild; human/JSON/help/cached/
dry-run/legacy controls; and unrelated-corpus access invariance.

The native public batch and supplemental controls are terminal: 115 CLI calls,
8.862482204 seconds of owner-process monotonic execution. The earlier mislabeled
legacy attempt retained normalized layout; a later new-vault setup used the wrong
initialization binding. Both setup failures and their original commands remain
recorded. Corrected controls use a fresh genuine legacy vault. These are preserved
harness failures, not evidence that the product passed those failed attempts.

The critic verified 345 returned citation occurrences, 22 unique source spans
and 42 exact reads without a byte/hash mismatch, including occupancy outputs.
Citation integrity, factual task completion, retrieval relevance and answer
completeness were assessed separately. Every task passed. The 0.5-point deduction
covers verbose human JSON/manual range transfer and generic cached warning
wording; neither caused a failed task or incorrect citation.

## Remaining gates and next milestone

This slice does not pass automatic HIGH, generated answers, full normalized
command parity/default activation, representative 25k/~2.5GB import/update/recovery,
other-host compatibility, live-provider behavior or native power-loss safety.
The latest broad regression and strict lint gates remain open. Local candidates
are unsigned and unnotarized; no public release or tag is implied.

The fresh priorities review recommends closing this bounded graph gate, packaging
the exact accepted binary, then running representative public import → cited
search/read → update → backup/cache-loss/rebuild at 10k and 25k under
[the existing capacity protocol](testing-large-vaults.md). That actual public-import
control is the next scaling experiment; further graph features and importer
microbenchmark series are deferred. Native completeness and coherent normalized
defaults remain subsequent milestones with their original gates.
